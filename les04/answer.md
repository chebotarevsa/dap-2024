
## 1. Медиана

**Медиана** — это значение, которое делит набор данных на две равные части: половина значений меньше медианы, половина — больше.

**Пример:** для ряда `[3, 1, 4, 2, 5]`

1. Сортируем: `[1, 2, 3, 4, 5]`
    
2. Центральный элемент → `3`
    

**Медиана = 3**

Если элементов чётное количество, медиана — среднее двух центральных значений.

## 2. Дисперсия

**Дисперсия** показывает, насколько разбросаны данные относительно среднего значения.

**Пример:** для `[3, 1, 4, 2, 5]`

- Среднее = 3
    
- Квадраты отклонений: `(3-3)²=0, (1-3)²=4, (4-3)²=1, (2-3)²=1, (5-3)²=4`
    
- Сумма = 10
    
- Дисперсия = 10 / 5 = 2
    

## 3. Среднеквадратичное отклонение (СКО)

**СКО** — это корень квадратный из дисперсии, показывает среднее отклонение значений от среднего, в тех же единицах.

**Пример:** для `[3, 1, 4, 2, 5]`

- Дисперсия = 2
    
- СКО = √2 ≈ 1.414
    

## 4. Series и DataFrame

- **Series** — одномерный массив с индексом, может содержать числа, строки и др.
    
- **DataFrame** — таблица с индексами и столбцами, каждый столбец может быть разного типа.
    

**Пример:**

```python
import pandas as pd

s = pd.Series([10, 20, 30], index=['a','b','c'])
df = pd.DataFrame({'A':[10,20,30], 'B':['x','y','z']})
```

## 5. Изменение индекса Series

Да, индекс можно изменить:

```python
s.index = ['x','y','z']          # прямое присвоение
s = s.rename({'x':'new_x'})       # через rename
s = s.set_axis(['p','q','r'])     # через set_axis
```

## 6. Сложение Series

- **Совпадающие индексы:** складываются по элементам → `s1 + s2`
    
- **Разные индексы:** результат с NaN там, где индексы не совпадают
    
- **Разные размеры:** автоматически выравнивается по индексам, отсутствующие значения = NaN
    
- **Разные типы:** NumPy выполняет приведение типов (int → float), строки не складываются как числа
    

## 7. DataFrame

- Двумерная таблица с индексами и именами столбцов
    
- Отличие от Series: 2D, разные типы столбцов, операции по строкам и столбцам

## 9. Разница между iloc и loc

|Характеристика|iloc|loc|
|---|---|---|
|Тип индексации|по позициям|по меткам|
|Диапазон|end не включается|end включается|
|Пример|`df.iloc[0:2]`|`df.loc['a':'c']`|


## 10. Добавление Series в DataFrame

Да, можно:

```python
df['C'] = new_series            # присвоение по имени
df = df.assign(C=new_series)    # через assign
df = pd.concat([df, new_series], axis=1)  # через concat
```
